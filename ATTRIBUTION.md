## What's original (the author's) vs. what's mine

| Status | Meaning |
|---|---|
| 🟦 **Original** | Unmodified or lightly modified file from the source repo, kept for learning/reference. Not claimed as my work. |
| 🟩 **My implementation** | Built by me — my own Terraform/code/scripts, my own deployment, my own write-up, based on the original day's *topic* but not copied from the original day's *code*. |
| 🟨 **My notes on original code** | Original author's code kept as-is, with my own added documentation: how I ran it, what broke, what I'd change. |
| ⬜ **Concept notes only** | I have not yet built a hands-on lab for this topic. Notes describe the concept only; no deployment or code is claimed. |

See the status table in the root `README.md` for the per-topic breakdown.
